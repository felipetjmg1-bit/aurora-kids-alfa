# AURORA KIDS ALFA · fluxo passo a passo

API demonstrativa para regra de horário digital em perfis.

## 1. CRIAR PERFIL DE TESTE

Selecionar perfil fictício e parâmetros de demonstração.

## 2. CONFIGURAR HORÁRIO

Definir janela permitida e regra de recolhimento digital.

## 3. ENVIAR SOLICITAÇÃO

Consultar a API FastAPI com o perfil e o horário.

## 4. AVALIAR REGRA

Executar a lógica de decisão implementada.

## 5. RETORNAR STATUS

Exibir o resultado demonstrativo para revisão do responsável.

## Resultado e limites

Protótipo de regra digital. Não substitui controles parentais completos nem avaliação de segurança infantil.
